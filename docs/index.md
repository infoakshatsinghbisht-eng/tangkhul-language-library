# Tangkhul Language Library Documentation

Welcome to the documentation for the **Tangkhul Language Library** (`tangkhul-language-library`), a modular Python toolkit designed for language preservation, linguistic analysis, vocabulary extraction, and cultural heritage documentation for the Tangkhul (Tangkhulic / Tibeto-Burman) language.

---

## Documentation Sections

- [Installation](installation.md) — Step-by-step installation instructions for Windows, Linux, and macOS.
- [Quickstart](quickstart.md) — Getting started with the currently implemented package foundation.
- [Architecture](architecture.md) — Library modular design, package layout, and data flow.
- [Data Sources & Provenance](data-sources.md) — How resources are catalogued with rigorous attribution.
- [Data Model & Schema](data-model.md) — Specifications for manifests, vocabulary entries, and provenance records.
- [Licensing & Permissions](licensing-and-permissions.md) — Ethical handling of cultural materials, community permissions, and intellectual property.
- [Contributing Data](contributing-data.md) — Guide for researchers, community speakers, and developers to contribute verified records.
