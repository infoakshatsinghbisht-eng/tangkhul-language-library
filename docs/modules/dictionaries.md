# Dictionaries Module (`tangkhul_lib.dictionaries`)

The **Dictionaries** module is a planned domain module focused on cataloguing, structuring, and indexing Tangkhul dictionaries, multilingual vocabularies, and wordlists.

---

## Planned Scope & Objectives

- **Lexicon Cataloguing**: Catalogue historical and contemporary dictionaries in `data/manifests/dictionaries.jsonl`.
- **Headword & Sense Ingestion**: Ingest dictionary headwords, grammatical categories, definitions, example sentences, and cross-references.
- **Multilingual Mapping**: Support mappings across Tangkhul, English, Manipuri (Meiteilon), and Hindi.
- **Dialectal Variation Tracking**: Record village-level lexical variants alongside standard Ukhrul forms.

---

## Current Status (Step 1)

- Architecture and directory structures initialized.
- Manifest schema supported in `dictionaries.jsonl`.
- Parsing engines and dictionary imports will be integrated in subsequent steps.
